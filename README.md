# JADEX FILMS

**Original Streaming Experience** — A luxury cinema and movie streaming platform UI built from scratch with HTML, CSS, and JavaScript.

## About the Project
Jadex Films is a curated streaming interface celebrating glamorous dramas, feel-good romance, high-fashion stories, and uplifting adventures.

## Design & Aesthetic
* **VIP Cinema Color Palette:** Combines deep Midnight Theater Black and Royal Velvet Plum surfaces with Rose Gold and Champagne Gold gradient highlights.
* **Premiere Typography:** Pairs *Cinzel* display titles with clean *Plus Jakarta Sans* interface copy.

## Features
* **Featured Premiere Hero:** Spotlight banner with match ratings, 4K HDR tags, and quick-action buttons.
* **Interactive Trailer Preview Modal:** Clicking **Play Now** launches a sleek VIP 4K HDR screening preview modal.
* **Live "+ My List" Watchlist Drawer:** Save titles from any row without duplicates, track your live counter in the navbar, and manage saved films inside a slide-out drawer.

## Built With
* **HTML5** — Semantic streaming layout & custom SVG monogram favicon
* **CSS3** — Custom variables, glassmorphism navbar, responsive poster grids, and gradient glow transitions
* **Vanilla JavaScript** — Dynamic watchlist state, duplicate prevention, and interactive modal/drawer controls
